> **Listas compartilhadas em tempo real.**
> `nossalista.leoferolive.com.br`

---

## 1. Visão do Produto

NossaLista é um aplicativo web de listas compartilhadas onde usuários podem criar diferentes tipos de lista, convidar outras pessoas e colaborar em tempo real. O foco é simplicidade, com uma interface moderna e minimalista.

---

## 3. Funcionalidades do MVP

### 3.1 Autenticação
- Login com Google (OAuth2) — método principal
- Login com email/senha — fallback
- Registro de usuário com username único (usado para convites)
- Sessão persistente via JWT
- Tutorial guiado no primeiro login por conta (com opção de replay manual)

### 3.2 Tipos de Lista (pré-definidos)

Cada tipo define quais campos um item possui:

| Tipo       | Campos do Item                          |
|-----------|------------------------------------------|
| 🛒 Compras | nome, quantidade, checkbox              |
| ✅ Tarefas  | nome, prazo (data), checkbox            |
| 🎁 Wishlist | nome, link/URL, checkbox               |
| 📝 Genérica | nome, checkbox                         |

### 3.3 Gestão de Listas
- Criar lista (escolher tipo + nome da lista)
- Editar nome da lista
- Excluir lista (apenas o dono)
- Visualizar todas as listas (próprias + compartilhadas)

### 3.4 Gestão de Itens
- Adicionar item à lista (campos variam por tipo)
- Editar item
- Marcar/desmarcar checkbox
- Remover item
- Reordenar itens (drag & drop — nice to have)

### 3.5 Compartilhamento
- Convidar por username (busca dentro do app)
- Convidar por link de convite (gera link único com expiração)
- Todos os convidados têm permissão total (CRUD de itens)
- Dono pode remover participantes
- Participante pode sair da lista

### 3.6 Sincronização em Tempo Real
- WebSocket (STOMP sobre SockJS)
- Alterações em itens refletem instantaneamente para todos os participantes online
- Indicador de quem está online na lista (nice to have)

### 3.7 Histórico
- Log simples de ações: quem fez o quê e quando
- Exemplos: "Leo adicionou 'Arroz'" · "Ana marcou 'Leite' como concluído"
- Visualização em timeline dentro da lista

## 4. Modelo de Dados (simplificado)

```
┌──────────────┐       ┌──────────────────┐
│    users     │       │   list_types     │
├──────────────┤       ├──────────────────┤
│ id (UUID)    │       │ id               │
│ username     │       │ name             │
│ email        │       │ slug             │
│ name         │       │ field_schema     │
│ avatar_url   │       │   (JSONB)        │
│ password     │       └──────────────────┘
│   (nullable) │
│ auth_provider│
│ onboarding_completed_at │
│ created_at   │
└──────┬───────┘
       │
       │ 1:N
       ▼
┌──────────────┐        ┌──────────────────┐
│    lists     │        │  list_members    │
├──────────────┤        ├──────────────────┤
│ id (UUID)    │◄──────►│ list_id          │
│ name         │  N:M   │ user_id          │
│ type_id      │        │ role (OWNER /    │
│ owner_id(FK) │        │       MEMBER)    │
│ invite_code  │        │ joined_at        │
│ created_at   │        └──────────────────┘
│ updated_at   │
└──────┬───────┘
       │
       │ 1:N
       ▼
┌──────────────────┐
│   list_items     │
├──────────────────┤
│ id (UUID)        │
│ list_id (FK)     │
│ name             │
│ checked          │
│ quantity         │
│   (nullable)     │
│ due_date         │
│   (nullable)     │
│ url (nullable)   │
│ position (int)   │
│ created_by (FK)  │
│ created_at       │
│ updated_at       │
└──────┬───────────┘
       │
       │ 1:N
       ▼
┌──────────────────┐
│  activity_log    │
├──────────────────┤
│ id (UUID)        │
│ list_id (FK)     │
│ user_id (FK)     │
│ action           │
│  (ADDED/CHECKED/ │
│   REMOVED/EDITED)│
│ target_name      │
│ details (JSONB)  │
│ created_at       │
└──────────────────┘
```

### Notas sobre o modelo:
- **list_types.field_schema**: JSONB que define os campos dinâmicos por tipo. Ex: `{"fields": [{"name": "quantity", "type": "number"}, {"name": "due_date", "type": "date"}]}`
- **list_items**: colunas nullable para campos opcionais — abordagem simples para o MVP. Alternativa futura: coluna JSONB para dados extras.
- **password nullable**: usuários que logam via Google não precisam de senha.
- **onboarding_completed_at nullable**: controla se o tutorial inicial já foi concluído para a conta.

## 6. API REST — Endpoints Principais

### Auth
```
POST   /api/auth/register          Registro email/senha
POST   /api/auth/login             Login email/senha
GET    /api/auth/google            Redirect OAuth2 Google
GET    /api/auth/google/callback   Callback OAuth2
POST   /api/auth/refresh           Refresh token
```

### Users
```
GET    /api/users/me               Perfil do usuário logado
PATCH  /api/users/me               Atualizar perfil
POST   /api/users/me/onboarding/complete  Marcar onboarding inicial como concluído
GET    /api/users/search?q=        Buscar por username (p/ convite)
```

### Lists
```
GET    /api/lists                  Listar listas do usuário
POST   /api/lists                  Criar lista
GET    /api/lists/{id}             Detalhe da lista
PATCH  /api/lists/{id}             Editar lista
DELETE /api/lists/{id}             Excluir lista (dono)
```

### List Members
```
POST   /api/lists/{id}/invite          Convidar por username
POST   /api/lists/{id}/invite-link     Gerar link de convite
POST   /api/lists/join/{inviteCode}    Aceitar convite via link
DELETE /api/lists/{id}/members/{uid}   Remover membro
POST   /api/lists/{id}/leave           Sair da lista
```

### List Items
```
GET    /api/lists/{id}/items       Listar itens
POST   /api/lists/{id}/items       Adicionar item
PATCH  /api/lists/{id}/items/{iid} Editar item
DELETE /api/lists/{id}/items/{iid} Remover item
PATCH  /api/lists/{id}/items/reorder  Reordenar
```

### Activity Log
```
GET    /api/lists/{id}/activity    Histórico da lista
```

## 7. WebSocket — Tópicos STOMP

```
SUBSCRIBE  /topic/list/{listId}          Receber atualizações da lista
SEND       /app/list/{listId}/item.add    Adicionar item
SEND       /app/list/{listId}/item.update Atualizar item
SEND       /app/list/{listId}/item.delete Remover item
SEND       /app/list/{listId}/item.check  Marcar/desmarcar
```

Mensagem de evento (broadcast):
```json
{
  "type": "ITEM_ADDED",
  "payload": { "id": "...", "name": "Arroz", "quantity": 2 },
  "userId": "uuid",
  "username": "leo",
  "timestamp": "2026-02-09T15:30:00Z"
}
```

## 10. Decisões Técnicas

| Decisão | Escolha | Justificativa |
|---------|---------|---------------|
| Campos por tipo de lista | Colunas nullable no `list_items` | Simples pro MVP; migrar para JSONB se escalar |
| Auth | JWT stateless | Funciona bem com WebSocket e SPA |
| Real-time | STOMP sobre WebSocket | Suporte nativo Spring, pub/sub por lista |
| CSS | Tailwind CSS | Rápido, minimalista, responsivo |
| Estado frontend | React Context + hooks | Sem necessidade de Redux pro MVP |
| Migrations | Flyway | Controle de schema versionado |
